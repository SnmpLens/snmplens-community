# Models

One directory per model — `models/<id>/`, named after the `id` inside its `model.json` — or a single
`models/<id>.json` for a model that needs no icon and no recording.

See [CONTRIBUTING.md](../CONTRIBUTING.md): how SnmpLens records a real device into a package, what the
package holds, the bounds it is read under, and what to anonymise before publishing a recording.
